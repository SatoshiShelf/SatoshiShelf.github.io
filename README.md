# Satoshi Shelf

An independent, Bitcoin-only digital storefront. Practical templates, spreadsheets, scripts, tools, and browser games — paid over Lightning, delivered instantly, no account or card required. On-chain fallback available.

- **About / press:** https://satoshishelf.github.io/about.html
- **Policies:** https://satoshishelf.github.io/policies.html

## What is here

This repository contains the public static storefront: product pages, previews, guides, assets, sitemap, feed, and the `llms.txt` index. It is hosted on GitHub Pages.

Product archives and payment verification are not part of the public site. The storefront does not install analytics, advertising pixels, or account-tracking scripts.
